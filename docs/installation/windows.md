# Windows使用教程
## 游戏准备
请确保你已经安装好了1.5+版本的*Getting Over It With Bennet Foddy*（以下简称GOI）。

[Steam](https://store.steampowered.com)：[Getting Over It](https://store.steampowered.com/app/240720)

## BepInEx环境准备
为GOI安装5.x版本的BepInEx插件框架。

[BepInEx Github Release](https://github.com/BepInEx/BepInEx/releases)：[BepInEx_win_x64_5.4.23.5.zip](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip)

下载完成后将`BepInEx_win_x64_5.4.23.5.zip`解压到GOI游戏根目录。

## 安装Mod
为GOI安装GOILauncher.Multiplayer的BepInEx插件。

[GOILauncher.Multiplayer Github Release](https://github.com/Zonakkis/GOILauncher.Multiplayer/releases)：[GOILauncher-Multiplayer-2.0-BepInEx.zip](https://github.com/Zonakkis/GOILauncher.Multiplayer/releases/)

下载完成后解压到GOI游戏根目录。
